MdMonitor Browser Extension

一键复制当前网页为 Markdown 链接

点击浏览器工具栏按钮，扩展会直接复制当前页面标题和网址，生成可被 MdMonitor 采集的 Markdown 链接。

需要额外操作

默认按点击临时授权。若你不想在不同站点反复确认，可以一次性授权所有网站。

如果你已经点过授权但浏览器仍然弹站点访问提示，通常是浏览器把这个扩展的 Site access 仍设成了按点击或当前站点未放行。

检测中

默认开启，生成 `* [ ] [标题](网址)` 这种待办格式。

关闭“启用前缀”后，这个值不会参与复制结果。

配合 MdMonitor 使用

这个扩展是给 MdMonitor 配套用的：浏览器里一键复制，桌面端负责自动采集、归档、搜索和后续回看。

桌面端安装包和扩展打包文件都会发布在 项目 Releases 页面 。

  1. 安装 MdMonitor 桌面端，并开启监控。
  2. 安装这个扩展，保留默认前缀格式。
  3. 浏览页面时点击工具栏按钮，MdMonitor 就会把链接收进当天文档。
